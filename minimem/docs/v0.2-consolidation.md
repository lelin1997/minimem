# minimem v0.2 巩固需求单

> 基于 P0-P3 + KC 修复后的技术债梳理 + 外部 review 反馈
> 目标：补完架构短板，提升工程质量，不加新功能

## 设计原则

1. **不加新功能** — 只补技术债和测试
2. **每个阶段留验证窗口** — 不再一天 17 commit
3. **runtime 验证优先** — typecheck + unit 过了不算完，必须启动服务跑一遍
4. **可回滚** — feature 分支 + 阶段性 commit

---

## P5-A: app 层编排落地

### 背景
P3 四层架构的 app 层是空壳（`export {}`），`src/index.ts` 仍在充当事实上的 app 入口。Dream 编排、Surface 同步编排散落在 domain 层。

### TODO

#### TODO-A01: 迁移 src/index.ts → src/app/main.ts
- `src/index.ts` 的启动编排（initDb → runMigrations → registerInfraPorts → initVectorStore → startScheduler → createRestApp → startMCP）迁入 `src/app/main.ts`
- `src/index.ts` 改为 re-export `app/main.js`
- 保留 package.json 的 `main` / `bin` 入口不变

#### TODO-A02: 抽取 Dream 编排到 app 层
- `domain/dream/dream-engine.ts` 里的 `triggerDream()` 编排逻辑（phase 顺序控制、错误恢复、session 管理）抽到 `app/dream-orchestrator.ts`
- domain 层只保留单 phase 的纯逻辑（runCompile / runConsolidation / runDream / runCleanup）
- app 层负责组合这些 phase

#### TODO-A03: 抽取 Surface 同步编排到 app 层
- compile 后的 surface sync 触发逻辑从 `domain/dream/compiler.ts` 抽到 `app/surface-orchestrator.ts`
- domain 层只暴露 `syncSurfaces(files)` 纯函数
- app 层决定何时同步、同步哪些文件

## P5-B: DataStore 拆分

### 背景
DataStore Facade 聚合了 31 个方法，违反 Interface Segregation Principle。任何 store 函数签名变化都要改 DataStore。

### TODO

#### TODO-B01: 拆分 DataStore 为 4 个 Repository 接口
- `ExperienceRepository` — createExperience / experienceExistsByHash / getUnprocessedExperiences / getPendingExperiences / markExperienceProcessed / getDb
- `FactRepository` — findFactsBySubject / getActiveMentalModels / createWorldFactsBatch
- `IndexRepository` — addToFts / removeFromFts / searchFts / lookupByCondition / lookupByPrefix / addConditionIndex
- `KnowledgePageRepository` — createKnowledgePage / getKnowledgePageBySlug / getAllKnowledgePages / getStalePages / getPendingCompileItems / enqueueCompile / markCompiled / markCompiledBatch / updateKnowledgePageContent / updateKnowledgePageMeta / updateLintStatus / searchKnowledgePages / incrementMemoryCount

#### TODO-B02: domain 代码按需 import 具体 Repository
- 不再 import 巨型 DataStore
- 每个文件只 import 它需要的 Repository（如 compiler.ts 只需要 KnowledgePageRepository + IndexRepository）
- infra/ports-registration.ts 分别注册 4 个 Repository
